              Terms and acronyms used on this page

              MLS Multiple Listing Service
              A regional database where agents list homes for sale. There are more than 800 in the US, and each one licenses its data feed with its own rules and rate limits.
              RESO Real Estate Standards Organization
              The body behind the RESO Data Dictionary (standard field names such as ListPrice) and the RESO Web API that most MLSs now use.
              RETS Real Estate Transaction Standard
              The older feed protocol some MLSs still use. Our adapters translate it into RESO fields.
              Golden record
              The one merged, trusted record per home, keyed by property_id. Every listing for that home updates it.
              property_id
              Our stable id for a physical home, built from the county code and the parcel number, with an address match as the fallback.
              Outbox
              A row written in the same database transaction as the record change. A relay publishes it as an event, so the record and the event never disagree.
              Version check
              Every consumer keeps the version it last applied and ignores anything older. It makes redelivery, races and replay harmless.
              H3 Uber's hexagon grid
              A global grid of hexagonal cells at several sizes. We tag each listing with its cells at resolutions 5, 7 and 9.
              PostGIS
              The geography extension for Postgres. We use it once per listing change to work out district, ZIP code and city.
              AlloyDB
              Google's managed, Postgres-compatible database. It holds the golden records and is the only place a property fact is written.
              Pub/Sub
              Google's managed publish and subscribe messaging. One topic carries property.changed, and each consumer has its own subscription.
              Cloud Tasks
              Google's managed task queue. One queue per MLS calls our ingest workers at the rate that MLS's contract allows.
              Valkey Memorystore for Valkey
              The open-source fork of Redis, with the same API. Google runs it for us as the search cache, card store and dedupe keys.
              OpenSearch
              The open-source search engine forked from Elasticsearch. We run it ourselves on Kubernetes (GKE) because ranking and geo filters are the product.
              Iceberg Apache Iceberg
              An open table format on Cloud Storage. BigQuery, Spark or Trino can read the same files, with time travel.
              BigQuery
              Google's serverless data warehouse, used for history, analytics and model training. Never on the user's request path.
              Cloud Run
              Google's service for running containers that scale with traffic, down to zero, billed per use.
              p95 95th percentile
              95 out of 100 requests are at least this fast. We set budgets on p95 rather than the average.
              QPS queries per second
              Search requests per second. A map pan or a filter change counts as one.
              CDN content delivery network
              Servers at the edge of the network that cache photos, map tiles and pages close to the user.
              TTL time to live
              How long a cached value or a dedupe key lives before it expires on its own.
              SET NX set if not exists
              A Valkey write that only succeeds the first time, which makes a cheap 'did we already send this?' check.
              Valuation model AVM, automated valuation model
              Our model that estimates a value for every home. Gradient-boosted trees (XGBoost) in a container, re-scored nightly.
              DR disaster recovery
              A standby copy in a second region that we promote if the primary region is lost.
              Committed use discount CUD
              A lower price on Google Cloud in exchange for committing to a steady amount of compute for one or three years.
              Read model
              A copy of the data shaped for one kind of read: the search index, the cache, alert posting lists, history in BigQuery. Each is rebuilt from events.
              Spot VMs
              Spare Google Cloud capacity at a deep discount that can be reclaimed at short notice. Fine for jobs that can restart.
